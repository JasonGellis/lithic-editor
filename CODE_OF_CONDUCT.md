# Code of Conduct

## Our standard

Lithic Editor is a project for everyone who works with lithic drawings. We want the
issue tracker, the pull requests and every other place where the project is discussed to
be open and respectful.

We expect every participant to:

- Be respectful of other people and of different points of view.
- Give and accept constructive feedback.
- Focus on what is best for the project and its users.
- Accept responsibility for mistakes and correct them.

We do not accept:

- Insults, personal attacks or derogatory comments.
- Harassment of any kind, in public or in private.
- Publication of other people's private information without their permission.
- Any other conduct that a reasonable person would find inappropriate in a professional
  setting.

## Scope

This code applies to all project spaces: the repository, the issue tracker, pull
requests, the documentation and any discussion about the project in public.

## Report a problem

Report unacceptable behaviour to the maintainer at <jg760@cam.ac.uk>. Every report is
read and treated in confidence. The maintainer decides on the response, which can be a
warning, a removal of comments, or a ban from the project spaces.
